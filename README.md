# tnayin
=======
"Խնդիր. «Օնլայն Խանութ» (Online Store)
Ստեղծիր 2 դաս՝ Product (Ապրանք) և ShoppingCart (Զամբյուղ)։

1-ին դաս՝ Product (Ապրանք)
Այս դասը նկարագրում է մեկ ապրանք։

__init__-ը պետք է ընդունի․

name (ապրանքի անունը)

price (գինը)

stock (քանակը խանութում, լռելյայն՝ 10)

2-րդ դաս՝ ShoppingCart (Զամբյուղ)
Այս դասը կառավարում է գնորդի զամբյուղը։

__init__-ը պետք է ստեղծի․

items (դատարկ ցուցակ [], որտեղ պահվելու են ավելացված ապրանքները)

Մեթոդները․

add_product(product, quantity) — Զամբյուղի մեջ ավելացնում է ապրանքը․

Նախ պետք է ստուգի․ արդյո՞ք խանութում (product.stock) կա պահանջված քանակությամբ ապրանք։

Եթե կա․ ապրանքն ու քանակը ավելացնում է items ցուցակի մեջ, իսկ product.stock-ից հանում է այդ քանակը։ Տպում է․ «Ավելացվեց [quantity] հատ [name]»։

Եթե չկա․ տպում է․ «Անբավարար քանակ խանութում: Առկա է ընդամենը [stock] հատ»։

remove_product(product) — Զամբյուղից ամբողջությամբ հանում է տվյալ ապրանքը, իսկ դրա քանակը վերադարձնում է խանութի պահեստ (product.stock)։

get_total() — Հաշվում և վերադարձնում (կամ տպում) է զամբյուղի ընդհանուր արժեքը (ամեն ապրանքի գին × քանակ)։

Ինչպես պետք է աշխատի (Օրինակ)․
Python
# Ստեղծում ենք ապրանքներ
laptop = Product("Laptop", 1200, stock=5)
phone = Product("iPhone", 800, stock=3)

# Ստեղծում ենք զամբյուղ
cart = ShoppingCart()

# Փորձում ենք գնել
cart.add_product(laptop, 2)  # Ավելացվեց 2 հատ Laptop
cart.add_product(phone, 5)   # Անբավարար քանակ խանութում: Առկա է ընդամենը 3 հատ

cart.get_total()             # Ընդհանուր գումարը՝ 2400$"
